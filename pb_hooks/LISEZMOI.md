# pb_hooks

Le code qui tourne côté serveur, dans PocketBase : un fichier `*.pb.js` par
règle (par exemple la date de fin posée toute seule quand une carte passe en
« Fait », partie 2).

Ce dossier est vide au départ, mais il existe exprès : PocketBase le surveille
dès le lancement, donc un fichier ajouté ici est pris en compte sans relancer
le serveur.
